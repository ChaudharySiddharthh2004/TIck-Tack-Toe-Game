# TIck-Tack-Toe-Game
🎮 Tic Tac Toe Game  A simple and interactive Tic Tac Toe game built with HTML, CSS, and JavaScript.  Two-player mode (Player X vs Player O)  Clean and responsive UI  Highlights winning combinations  Restart/Reset functionality  This project is great for practicing DOM manipulation, event handling, and game logic using vanilla JavaScript.
